# 📊 Organizador de IRPF - Planilha de Consolidação de Dados

Uma ferramenta prática e intuitiva em Excel desenvolvida para auxiliar contribuintes na coleta, organização e consolidação das informações financeiras necessárias para o preenchimento da Declaração de Ajuste Anual do Imposto de Renda Pessoa Física (IRPF).

---

## 📌 Sobre o Projeto

Preencher a declaração do IRPF costuma ser um desafio devido à dispersão de comprovantes, informes de rendimentos e registros de bens. Este projeto resolve esse problema centralizando todas as informações essenciais em uma única estrutura navegável de abas, garantindo maior controle financeiro e evitando inconsistências no envio à Receita Federal.

---

## 🗂️️ Estrutura da Planilha

A planilha está dividida em 3 abas principais integradas por navegação simplificada:

### 1. 👤 Identificação do Contribuinte (`Dados Pessoais`)

* **Cadastro Geral:** Nome, CPF, Data de Nascimento e Raça/Cor.
* **Endereço Completo:** Logradouro, número, complemento, bairro, município, UF e CEP.
* **Contato & Status:** Telefone, celular, estado civil (cônjuge) e sinalização de alterações cadastrais.

### 2. 💰 Rendimentos (`Rendimentos`)

* **Rendimentos Tributáveis:** Dados de fontes pagadoras (CNPJ/Razão Social), recebimentos, IRRF, 13º salário e IRRF sobre 13º.
* **Rendimentos Isentos ou Não Tributáveis:** Controle de Lucros e Dividendos recebidos, rendimentos de caderneta de poupança, entre outros.
* **Rendimentos Sujeitos à Tributação Exclusiva/Definitiva:** Espaço dedicado para ganhos de capital e investimentos.

### 3. 🏠 Bens e Direitos (`Bens e Direitos`)

* **Categorização por Grupo:** Imóveis, bens móveis, aplicações/investimentos, créditos, fundos, criptoativos e outros.
* **Histórico Patrimonial:** Comparativo direto entre a situação no ano anterior e a situação no ano exercício.
* **Campo de Discriminação:** Detalhamento do bem/direito conforme exigido no programa do IRPF.

## 🚀 Como Usar

1. **Baixe o repositório:**
```bash
git clone https://github.com/seu-usuario/seu-repositorio.git

```


2. **Abra o arquivo:** Abra o arquivo `Desafio - Organizador de IRPF.xlsx` utilizando o Microsoft Excel ou software compatível (Google Planilhas, LibreOffice Calc).
3. **Preencha os campos:** Navegue entre as abas utilizando as seções de menu superior ou inferior e insira as informações de acordo com seus Informes de Rendimentos e comprovantes.
4. **Exporte para o Programa IRPF:** Utilize a planilha preenchida como um guia consolidado de consulta durante o preenchimento da declaração oficial.
